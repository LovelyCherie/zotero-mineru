# 多篇学术论文综合分析任务(防幻觉版)

下面是多篇学术论文的 markdown 全文,每篇以分隔线隔开,头部 YAML 包含标题(title)、作者(authors)、年份(year)、DOI。

硬性规则:

1. 所有观点断言必须严格基于提供的文本,原文不存在的,绝对禁止编造。
2. 每一条结论必须标注来源,格式为(作者, 年份),取自该篇 YAML 头;同一出处可合并标注。
3. 如果材料信息不足,直接写【原文未提及】,禁止脑补推断。
4. 忠于原文表述,禁止随意扩写;引用原文时用直引或紧贴原文的转述。

常见任务模板(在下方【任务】处替换/组合):

- 梳理研究脉络:按时间线组织各篇的核心问题、方法、结论与相互引用关系,指出演进与分歧。
- 对比方法:逐篇列出方法、数据集/对象、评价指标、关键假设,做成对比表或逐条对比,并说明不可直接比较之处。
- 总结研究局限:逐篇列出作者自述的局限(标注出处);全文未提及的局限维度写【原文未提及】,不得代作者补充。
- 交叉提问:回答你提出的问题,答案若横跨多篇,逐条标注来源。

输出要求:

- 结论句末尾一律带(作者, 年份)。
- 信息不足处显式写【原文未提及】。
- 分析之前先列出本次实际读到的文献清单(序号、作者、年份、标题),未出现在清单里的文献一律视为不存在。
